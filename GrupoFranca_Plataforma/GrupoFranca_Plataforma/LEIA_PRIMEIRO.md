# Grupo França Comercial 1.3

1. Extraia o projeto em uma pasta nova e abra **GrupoFranca_Plataforma**.
2. Execute `configurar.bat` e depois `iniciar.bat`.
3. O navegador abrirá a plataforma. Crie sua senha de gerente; o usuário é **igor**.
4. Use **Equipe → Usuários** para cadastrar funcionários e **Equipe → Distribuição** para distribuir contatos.

No PowerShell, use `./configurar.bat` e `./iniciar.bat` (ou o equivalente com barra invertida). Execute na pasta que contém esses arquivos, não dentro de frontend.

Leia [GUIA_VERSAO_1_3.md](GUIA_VERSAO_1_3.md) para atualização, acessos, permissões, indicadores e limites desta entrega.

O código completo por escrito está em [CODIGOS_COMPLETOS_1_3.md](CODIGOS_COMPLETOS_1_3.md). O ZIP já inclui a interface compilada. Os dados anteriores permanecem no diretório local da aplicação e a inicialização cria um backup antes de acrescentar tabelas.

O servidor continua local. A implantação para acesso simultâneo em vários computadores será uma etapa separada.
